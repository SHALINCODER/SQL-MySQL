# SQL Learning Repository

This repository contains a collection of SQL scripts covering various fundamental and advanced SQL concepts. It serves as a comprehensive resource for learning and practicing SQL database operations.

## Contents

### Basic SQL Operations
- `create-table-and-insert-values.sql`: Examples of creating tables and inserting data
- `likeandgroupby.sql`: Demonstrations of LIKE operator and GROUP BY clauses
- `secondlargest.sql`: Query techniques for finding second largest values

### Intermediate SQL
- `functions.sql`: Various SQL functions and their usage
- `joinsandfunctions.sql`: Examples of different types of JOIN operations combined with functions
- `subqueries.sql`: Examples of subquery implementations
- `views_and_trims.sql`: Creating and managing views, string manipulation with TRIM functions

### Advanced SQL Concepts
- `rank_denserank_temptable.sql`: Usage of RANK, DENSE_RANK functions and temporary tables
- `triggers.sql`: Database trigger implementations
- `with.sql`: Common Table Expressions (CTE) using WITH clause

### Practice Tasks
- `task_2_03_sept_2025.sql`: SQL practice problems and solutions
- `task_3_04_sepet_2025.sql`: Additional SQL exercises
- `part-2 (1).sql` & `part-2 (2).sql`: Extended practice scenarios

## Topics Covered

- Table Creation and Data Manipulation
- Data Querying and Filtering
- Aggregation Functions
- JOINs (Inner, Left, Right, Full)
- Subqueries
- Views
- Triggers
- Window Functions (RANK, DENSE_RANK)
- Common Table Expressions
- String Functions and Data Formatting
- Group By and Having Clauses
- LIKE Operator
- Temporary Tables

## Purpose

This repository serves as a learning resource for SQL, demonstrating various SQL concepts from basic to advanced levels. Each file contains practical examples and implementations of different SQL features, making it useful for both learning and reference purposes.

## Usage

Each SQL file can be executed in any SQL database management system that supports standard SQL syntax. The files contain both the queries and often include comments explaining the operations being performed.

---

Feel free to explore each file to learn and practice different SQL concepts. The repository is structured to progress from basic to more advanced topics.
